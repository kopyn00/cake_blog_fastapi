# Cake Blog FastAPI

A cake baking blog application built with **FastAPI**, **SQLAlchemy** and **Jinja2**.

The project was created as a learning project while following [Corey Schafer's FastAPI Full Course](https://github.com/CoreyMSchafer/FastAPI-Full-Course/).

The original tutorial provided the foundation for learning FastAPI. I use this project to practice backend development and gradually extend it with my own features and improvements.

## Technologies

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- Jinja2
- SQLite
- HTML / CSS

## Project Goals

- Learn FastAPI and REST API development.
- Practice database integration with SQLAlchemy.
- Understand data validation with Pydantic.
- Implement user authentication and authorization.
- Build server-side rendered pages with Jinja2.
